How to use one

Drop the downloaded file into a folder named after the skill, inside your Claude skills directory. Claude reads the description and loads the skill on its own when your request matches — there's nothing to invoke. 

~/.claude/skills/prd-writer/SKILL.md

Works in Claude Code and any agent that reads skill files. Free to take, edit, and make your own — the opinions in them are mine, and you should overwrite them with yours.

Common questions

How does AI change the PM skill stack? expand_more

AI automates the "glue" work — PRDs, ticket triage, status syncs — and rewards higher-order skills: clear problem definition, ethical guardrails, prompt engineering, and orchestrating AI agents alongside human teammates. See the Agent Lab for concrete examples.

What is a Claude Skill, and how is it different from a prompt? expand_more

A prompt is something you retype every time. A skill is a markdown file the agent loads by itself when the work matches — it has a name, a description that acts as the trigger, and the instructions underneath. The practical difference is consistency: every PRD comes out with non-goals in it because the skill says so, not because you remembered to ask.

Why write your own skills instead of using generic PM templates? expand_more

A skill earns its place only if it encodes an opinion the model wouldn't otherwise hold. Reproducing a public PRD template adds nothing — Claude already knows it. The value is in the rules you've earned the hard way: always name the riskiest assumption, never estimate in story points, default AI bets to a foundation model before a custom one, flag every number by confidence.
